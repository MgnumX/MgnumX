## Selected work

### <img src="assets/dot-jobs.svg" alt="" width="14" height="14"> [jobs-es](https://github.com/MgnumX/jobs-es) — Spanish job-market scraper

Nine job-portal adapters behind a single interface, salary normalization with
guardrails written from real parser regressions, SQLite storage, and a
standalone offline HTML report. 16 offline tests, CI on every push. Adding a
portal is one file.

<img src="assets/chips-jobs.svg" alt="Python, httpx, SQLite, pytest, GitHub Actions">

### <img src="assets/dot-marihuaneros.svg" alt="" width="14" height="14"> [marihuaneros](https://marihuaneros.com) — independent publication

Static Astro site with its own editorial and SEO validator that runs on every
build, automatic Open Graph image generation, and deploy to Cloudflare Pages
only from `main`. No UI framework, no backend.

<img src="assets/chips-marihuaneros.svg" alt="Astro, TypeScript, Cloudflare Pages">

### <img src="assets/dot-scraper.svg" alt="" width="14" height="14"> [scraper-empleos](https://github.com/MgnumX/scraper-empleos) — ATS job scraper

Rate-limited ATS scraper with a 24-hour cache and 12 deterministic tests.

<img src="assets/chips-scraper.svg" alt="Python, pytest">

### <img src="assets/dot-qa.svg" alt="" width="14" height="14"> [qa-playwright-demo](https://github.com/MgnumX/qa-playwright-demo) — E2E suite

Four deterministic Playwright tests against public demo sites, wired for CI.

<img src="assets/chips-qa.svg" alt="Playwright, JavaScript">

### <img src="assets/dot-dj-ai.svg" alt="" width="14" height="14"> [dj-ai](https://github.com/MgnumX/dj-ai) — audio analysis and DJ-set planner

Analyzes local tracks and plans harmonic, BPM-aware sets before cutting segments and mixing them.

<img src="assets/chips-dj-ai.svg" alt="Python, librosa, NumPy, SciPy, pytest">

### <img src="assets/dot-oniro.svg" alt="" width="14" height="14"> [oniro](https://github.com/MgnumX/oniro) — Spanish-first dream journal

Stores entries in local SQLite and requests Spanish interpretations from an OpenAI-compatible LLM; includes a PWA and spec-first project docs.

<img src="assets/chips-oniro.svg" alt="Python, FastAPI, SQLite, LLM, pytest">
