## Selected work

### [jobs-es](https://github.com/MgnumX/jobs-es) — Spanish job-market scraper

Nine job-portal adapters behind a single interface, salary normalization with
guardrails written from real parser regressions, SQLite storage, and a
standalone offline HTML report. 16 offline tests, CI on every push. Adding a
portal is one file.

`Python` `httpx` `SQLite` `pytest` `GitHub Actions`

### [marihuaneros](https://github.com/MgnumX/marihuaneros) — independent publication

Static Astro site with its own editorial and SEO validator that runs on every
build, automatic Open Graph image generation, and deploy to Cloudflare Pages
only from `main`. No UI framework, no backend.

`Astro` `TypeScript` `Cloudflare Pages`

### [scraper-empleos](https://github.com/MgnumX/scraper-empleos) — ATS job scraper

Rate-limited ATS scraper with a 24-hour cache and 12 deterministic tests.

`Python` `pytest`

### [qa-playwright-demo](https://github.com/MgnumX/qa-playwright-demo) — E2E suite

Four deterministic Playwright tests against public demo sites, wired for CI.

`Playwright` `JavaScript`

## Built locally, not published

- **dj-ai** — music-information-retrieval pipeline: BPM estimation, key
  detection by Krumhansl-Schmuckler chroma correlation, integrated loudness to
  BS.1770, drop detection from onset flux, then a constrained set planner over
  the Camelot wheel with BPM ramps and an energy curve. 2.4k lines of Python.
- **oniro** — FastAPI + LLM dream journal, Spanish-first. OpenAI-compatible
  client, SQLite persistence, PWA frontend, and an offline pytest suite with
  the model call injected. Built spec-first: spec, plan and acceptance
  scenarios before code.
